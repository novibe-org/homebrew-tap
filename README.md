# homebrew-tap

Homebrew formulas for the tools novibe-org ships.

```bash
brew install novibe-org/tap/agentbox
```

Or tap once, then install by name:

```bash
brew tap novibe-org/tap
brew install agentbox
```

| Formula | Project |
| --- | --- |
| `agentbox` | [novibe-org/agentbox](https://github.com/novibe-org/agentbox) |

Each project's release workflow writes its own formula here; don't edit them by hand.
